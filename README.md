Software engineer in Yerevan, Armenia. I build the whole thing: frontend,
backend, and whatever else it needs. Python is my first choice, Rust when
something has to be fast, and these days I write in far more languages than
those two. One of them is my own: I make [Ferron](https://ferron-lang.dev), a
programming language.

## How I work

Most of my code is now written together with AI agents, often several at once.
That changed what one person can take on: a database engine, a programming
language, a desktop bar, each in whatever language fits it. The typing got
cheap. Knowing what to build, and telling a good answer from a plausible one,
did not, and that is the part I enjoy.

## Now

_Updated: November 2026_

- [Ferron](https://ferron-lang.dev) is the biggest thing I have made: a
  statically typed language compiled to native code, with errors as values, no
  null, and no borrow checker. I designed it on paper for more than a year
  before the first commit. Its compiler is now written in Ferron and runs in
  the browser: try the [playground](https://ferron-lang.dev/playground) or the
  [tour](https://ferron-lang.dev/tour).
- At work I build services end to end. FastAPI over Postgres is how I ship a
  backend, and the problem I keep coming back to is finding things in messy
  documents: PDFs and Word files that nobody planned for.
- [`stellardb`](https://github.com/vadim-su/stellardb) is where the search
  ideas go when they need an engine: documents, graphs, vectors, and full-text
  search in one database, in Rust.
- Editor support for languages that have none yet: Mojo, and now Ferron.
- My desktop is Omarchy, and its bar is slowly becoming mine. The widgets are
  below.
